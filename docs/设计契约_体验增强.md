# 设计契约 · 体验增强轮（v4 · 冻结）

> 本轮目标（用户原话）：「再给我增加更多功能，更完整，更有意思，页面更好看，更易于上手」。
> 本文件是唯一的事实源。数值/接口/文案以本文件为准，变动必须由 Lead 改本文件并通知全员。

## 0. 硬约束（不许破）

1. 零构建、纯静态、断网可跑：不引 ES module、不 fetch JSON、不加任何第三方依赖、**不新增外链 http(s)**。
2. 状态机冻结：不新增 STATE、不改 ALLOWED 迁移表；`applyEffect` 仍是唯一资源变更入口。
3. 所有新数据必须进 `data/*.json` → `tools/build-data.js` 生成 `js/data.js`（`--check` 必须 exit 0）。
4. 不新增布局块级元素：新 UI 用 `position:fixed` / 绝对定位 / 弹层，六档视口不得出滚动条。
5. 文案≤28 字（旁白）/ ≤22 字（按钮与提示），不剧透「哪轮撒谎」。
6. `localStorage` 一律走 `state.js` 的 `CodexStore` 封装（读档失败静默降级，不白屏）。
7. 所有人**不许跑 git**，提交统一由 Lead 做。

## 2. 状态与存储契约（Lead 独占：js/state.js）

### 2.1 新增 state 字段（`createInitialState` 模板）

```js
personality: 'sarcastic',   // 'sarcastic' | 'gentle' | 'crazy'
seedTag: null,              // 本局种子标签（普通模式写实际 seed 字符串；演示模式 '20261024'）
achievements: {},           // { [achievementId]: true } 本局新解锁的（用于 toast 去重）
stats: {
  games: 0, totalCoins: 0, bestCoins: 0, bestRound: 0,
  challenges: 0, challengeWins: 0, endings: 0
},
flags: {
  ...现有 flags,
  onboarded: false,         // 本进程内：是否已看过新手引导（持久化在 prefs）
  portraitWarned: false     // 竖屏提示只弹一次
}
```

### 2.2 新增存储键（`STORE_KEYS`）

| 键 | 内容 |
|---|---|
| `three_doors_stats_v1` | `{ games, totalCoins, bestCoins, bestRound, challenges, challengeWins, endings: [endingId...] }` |
| `three_doors_achievements_v1` | `{ [achievementId]: true }`（永久解锁） |
| `three_doors_prefs_v1` | `{ personality:'sarcastic', bgm:true, sfx:true, animSpeed:1, onboarded:false }` |

`CodexStore` 增加：`loadStats/saveStats/clearStats`、`loadAchievements/saveAchievements/clearAchievements`、`loadPrefs/savePrefs/clearPrefs`；`clearAll()` 一并清理（设置面板「清空全部数据」用）。

### 2.3 引擎接口（Lead 独占：js/game.js）

- `Game.personality()` / `Game.setPersonality(id)`：读写 `state.personality`，持久化到 prefs；非法 id 忽略。
- `Game.prefs()` → `{personality,bgm,sfx,animSpeed,onboarded}`；`Game.savePref(key,value)`（白名单键）。
- `Game.achievements()` → `[{id,name,desc,icon,unlocked}]`（合并 `GameData.achievements` + 本地永久解锁 + 本局判定）。
- `Game.stats()` → `{games,totalCoins,bestCoins,bestRound,challenges,challengeWins,challengeRate,endings}`（读档案 + 本局未落盘部分）。
- `Game.seedTag()` → 演示 `'20261024'` / 普通模式 `String(seed)`；`Game.seedUrl()` → `'index.html?seed=' + seed`。
- `Game.tutorialSteps()` → `[{id,title,text,anchor}]`（实际五步：`tut_door/tut_narrator/tut_decide/tut_challenge/tut_cashout`，首步 anchor=`'doors'`，覆盖 `'doors'|'decide'|'cashout'`；ui.js 用来定位气泡）。
- 新增 `action` 类型（在 `action()` 里加 case，不改迁移表）：
  - `{type:'set_personality', id}`（任意阶段，重开弹层）
  - `{type:'set_pref', key, value}`（bgm/sfx/animSpeed/onboarded）
  - `{type:'save_seed'}` → 结算页复制种子（返回 seed 文本供 ui 复制）
  - `{type:'tutorial_done'}` → 置 `flags.onboarded=true` + prefs.onboarded=true
  - `{type:'open_help'}` → 弹 `kind:'help'` 弹层
  - `{type:'open_settings'}` → 弹 `kind:'settings'` 弹层
  - `{type:'clear_save'}` → `Game.showClearSaveConfirm()` 二次确认弹层
  - `{type:'apply_speed', value}` 合并进 set_pref
- 成就判定：`Game._checkAchievements(trigger)` 在 `settleRound` / `cashout` / `gameOver` / `challenge()` 之后调用；解锁即 `toast('成就解锁：'+name)` + 写 `three_doors_achievements_v1`。
- 局终统计：`cashout` 与 `gameOver` 写 `stats`（games+1、totalCoins、bestCoins、bestRound、challenges、challengeWins、endings 去重）。
- `?seed=NNN` 进 init：`init` 读 `location.search`，`seed` 参数优先于 `rehearsal`；`?rehearsal=1` 行为保持。
- 结算弹层新增「种子：xxxx」一行 + 「复制种子」按钮（`choice:'save_seed'`）。

### 3.2 `data/achievements.json`（新，恰好 10 条）

`personas`（玩过的人格数≥N）、`clean`（单局 0 次质疑失败且收手）。

10 条（id/名称/图标/check 建议值，文案自拟 ≤40 字）：

## 4. 表现层契约（ui-render 独占：js/ui.js、style.css）

### 4.1 G1 新手引导

- `UI.init` 后若 `!Game.prefs().onboarded`，`UI.startTutorial()`：按 `Game.tutorialSteps()` 渲染 `#tutorial` 气泡（`position:fixed`，高亮锚点元素 `.is-tutorial-target`），「下一步」推进（末步 = 「开始」→ `action({type:'tutorial_done'})` + `action({type:'start',mode:demo|normal})`），「跳过」直接 done。
- 引导期间不阻塞点击（`#tutorial` 除气泡外 `pointer-events:none`）；任何游戏 action 导致 phase 变化时若引导未完成也自动 done（防卡死）。

### 4.2 G2 键盘

- `UI.init` 注册 `keydown`（`document`）：
  `1/2/3` → `pick`；`q/Q` → `decide:challenge`；`d/D` → `decide:double`；`s/S` → `decide:switch`；`c/C` → `decide:cashout`；
  `space` → 开始（IDLE）/继续（弹层有 primary）；`m/M` → `toggle_mute`；`?`/`h` → `open_help`；`Esc` → `closeModal`（弹层时；**必选流程弹层 `round`/`cashout`/`gameover` 除外**，避免按 Esc 后停在无弹层的状态里；无按钮弹层照常关闭）。
- 只在这些 phase 有效（不合法时忽略，不报错）；输入框/文本框获得焦点时不拦截（当前无输入框，写好判断即可）。
- `#btn-help` / `#btn-settings` 点击 → `action({type:'open_help'|'open_settings'})`。

### 4.3 G3 人格

- 设置弹层（`kind:'settings'`）内 `openModal` 渲染 `#settings-body`，含：三种人格单选（`.persona-card[data-persona]`，当前项 `.is-active`）、BGM 开关、音效开关、动画速度（0.5/1/1.5 三档）、「清空全部数据」按钮（`choice:'confirm_clear'`）。
- 页面右下角显示当前人格小徽标（`#persona-chip`，`position:fixed`，点击打开设置）。人格图标/名称来自 `GameData.personasById`。
- 旁白面板显示人格图标（`#narrator-text` 前缀），结算时若 `state.settleLine` 存在则显示点评行。

### 4.4 G4 成就 / G5 统计（图鉴弹层扩展）

- `kind:'codex'` 弹层增加两个区块：`#codex-achievements`（成就墙：`Game.achievements()` 渲染 `.ach-card.is-locked`，每卡 icon/name/desc）、`#codex-stats`（统计卡：局数/最佳金币/最佳轮次/质疑成功率/结局数）。
- 成就解锁 toast 由 game.js 触发（UI 只显示），成就墙即时刷新：`openModal(kind:'codex')` 时重新取数。

### 4.5 G6 种子分享

- 结算弹层新增「种子：xxxx」行 + 「复制种子」按钮（`choice:'save_seed'`）；点击后 `UI.toast('种子已复制')`（`navigator.clipboard` 可用则复制，不可用则只提示文本）。

### 4.6 G7 美术升级（六档视口不溢出）

- 舞台：幕布两侧 `.curtain`、顶部聚光灯 `.spotlight`（纯 CSS 渐变/伪元素）、暗角 vignette（`#stage::after`）。
- 门卡：浮雕边框、门把手 `.door-knob`、木纹/金属质感（`repeating-linear-gradient`）、悬停微倾（`transform: rotateY`）、选中 `.is-picked` 金色描边。
- 首屏：标题艺术字（`#boot-title` 描边/阴影/渐变文字）、副标题、两个开始按钮加强质感。
- HUD：金币/怀疑值/耐心 前置 SVG 图标（复用现有 `<symbol>`，新增 `ic-coins/ic-eye/ic-heart`）。
- 结算：`#confetti` 里生成 40 个 `.confetti-piece`（≤1.2s 后清空），`prefers-reduced-motion` 下不生成。
- 所有新视觉不得产生滚动条（`overflow` 只裁装饰层）、对比度保持 ≥4.5:1。

### 4.7 G8 竖屏提示

- `resize` 监听：`innerHeight < 400` 且非 `rehearsal` 时显示 `#portrait-hint`（居中浮层，`pointer-events:none`，「建议横屏体验」），恢复后隐藏；只在首次触发时 `action({type:'set_pref',key:'portraitWarned',value:true})`，不重复打断。
