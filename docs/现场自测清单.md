# 现场自测清单（演示前 30 分钟跑一遍）

对应《三扇门_别信旁白_开工清单》阶段 6「演示保障」与阶段 7「演示前自测」。全部在**浏览器里手工跑**，每项后面留了记录位。自动验收另见文末。

## 0. 环境预检（约 5 分钟）

- [ ] 打开方式：双击 `index.html`（`file://`，零依赖、断网可用）。若浏览器拦截本地文件，再退化到 `python -m http.server 8000` 后访问 `http://127.0.0.1:8000/`。
- [ ] 浏览器缩放 = 100%；窗口/F11 全屏，投影 16:9（1920×1080 或 1280×720）。
- [ ] 系统音量约 30%，先点一次「静音」再取消，确认开关有反馈。
- [ ] 确认没有任何外链请求：页面在断网状态下也能完整跑完（见第 4 项）。
- [ ] 关掉其它占屏窗口；提前把 `README.md` 与 `docs/ROLLBACK.md` 关掉，避免演示时切换窗口。

## 1. 无控制台报错（阶段 7）

- [ ] 按 F12 → Console，刷新页面：**不应有任何红色报错**。警告若出现应仅是 `[三扇门]` 前缀的调试信息。
- [ ] 记录：Console 条数 ______

## 2. 演示模式 3 分钟内完整演完（阶段 4 / 阶段 7，P0）

点「开始（演示模式）」，固定种子 `20261024`，剧本三轮：

| 轮次 | 门面 | 主持人开 | 剧情 | 预期结果 |
| --- | --- | --- | --- | --- |
| 第 1 轮 | small_prize / empty / bomb | 2 号门（bomb） | 旁白说真话 | 开出小奖 → 金币 130 |
| 第 2 轮 | empty / big_prize / trap | 1 号门（empty） | 旁白撒谎 | 点门 → **质疑旁白**成功 → 金币 250、得到真实提示 |
| 第 3 轮 | trap / big_prize / empty | 1 号门（trap） | 旁白使劲撒谎 | 拿到大奖后 **主动收手** → 结算页 |

- [ ] 三个高光点都出现：**小奖反馈 / 质疑反杀 / 收手结算**
- [ ] 结算页显示：最终金币 `250`、闯到第 3 轮、称号「欧皇候选」、本轮高光一句话
- [ ] 掐表：从点「开始」到结算页弹出 ______ 秒（要求 ≤ 180 秒）

## 3. 一键重置立即重演（阶段 4 P1 / 阶段 7）

- [ ] 在任意状态点右上角「重置」：**1 秒内**回到演示起点（第 1 轮、金币 100 / 怀疑值 2 / 耐心 3）。
- [ ] 再点「开始（演示模式）」：三轮结果与上一次**完全一致**（固定种子）。
- 记录：重置耗时 ______ 秒；两次结果是否一致 ______

- [ ] 断言无外链：页面只在本地加载 `style.css` + `js/*.js`，没有 http(s) 图片、字体、音效、接口。

## 5. 结算页与图鉴（阶段 3 / 阶段 5）

- [ ] 结算页有「再来一局」与「看图鉴」两个按钮。
- [ ] 点「看图鉴」：显示物品图鉴、语录图鉴、结局称号、最佳金币/最高轮次。
- [ ] 点「关闭」：回到结算页（不会把玩家卡在空弹层里）。
- [ ] 点「清空收集进度」：图鉴清零并给出提示；刷新页面后仍是空的。
- [ ] 刷新页面后再玩一局：已经解锁过的物品/语录/称号仍在（存档键 `three_doors_codex_v1`、`three_doors_best_v1`）。
- [ ] 结算页常驻娱乐声明：「游戏内金币纯属娱乐，非真实货币」。

## 备用方案：第 3 轮出问题怎么办（阶段 7）

若第 3 轮（大奖 → 收手）出现任何意外，**不要现场修**，直接改演「第 2 轮质疑反杀」收尾：

1. 点「重置」→「开始（演示模式）」。
2. 第 1 轮正常开到小奖（建立反馈）。
3. 第 2 轮点门 → 点「质疑旁白」→ 旁白被戳穿（+20 金币 + 真实提示）→ 坚持/换门 → 开奖。
4. 在本轮结算页直接点「见好就收」进结算页，口播说明「第 3 轮大奖环节今天略过」。
5. 结算页照常展示金币、轮次、称号与娱乐声明。

**保命四项**（时间被砍也只砍这四项之外的内容）：单轮闭环 → 质疑反杀 → 固定种子演示模式 → 一键重置。
