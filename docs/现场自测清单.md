# 现场自测清单（演示前 30 分钟跑一遍）

对应《三扇门_别信旁白_开工清单》阶段 6「演示保障」与阶段 7「演示前自测」。全部在**浏览器里手工跑**，每项后面留了记录位。自动验收另见文末。

## 0. 环境预检（约 5 分钟）

- [ ] 打开方式：双击 `index.html`（`file://`，零依赖、断网可用）。若浏览器拦截本地文件，再退化到 `python -m http.server 8000` 后访问 `http://127.0.0.1:8000/`。
- [ ] 浏览器缩放 = 100%；窗口/F11 全屏，投影 16:9（1920×1080 或 1280×720）。
- [ ] 系统音量约 30%，先点一次「静音」再取消，确认开关有反馈。
- [ ] 确认没有任何外链请求：页面在断网状态下也能完整跑完（见第 4 项）。
- [ ] 关掉其它占屏窗口；提前把 `README.md` 与 `docs/ROLLBACK.md` 关掉，避免演示时切换窗口。

## 1. 无控制台报错（阶段 7）

- [ ] 按 F12 → Console，刷新页面：**不应有任何红色报错**。警告若出现应仅是 `[三扇门]` 前缀的调试信息。
- [ ] 记录：Console 条数 ______

## 2. 演示模式 3 分钟内完整演完（阶段 4 / 阶段 7，P0）

点「开始（演示模式）」，固定种子 `20261024`，剧本三轮：

| 轮次 | 门面 | 主持人开 | 剧情 | 预期结果 |
| --- | --- | --- | --- | --- |
| 第 1 轮 | small_prize / empty / bomb | **3 号门**（bomb，slot 2） | 旁白说真话 | 开出小奖 → 金币 130 |
| 第 2 轮 | empty / big_prize / trap | 1 号门（empty，slot 0） | 旁白撒谎 | 点门 → **质疑旁白**成功 → 金币 250、得到真实提示 |
| 第 3 轮 | trap / big_prize / empty | 1 号门（trap，slot 0；**仅当你在本轮先点门时**） | 旁白使劲撒谎 | **直接收手** → 结算页（金币 250）；若先点 2 号门可拿大奖（+100 → 350）再收手 |

> 门号一律按**屏幕上显示的编号**（= `seed_demo.json` 的 `hostOpensSlot` + 1）。第 1 轮开的是 3 号门不是 2 号门。
>
> **不要手动点「换门」**：自动演示走的是「坚持本门 + 质疑反杀」，不触发换门；手动换门在没有换门券时要扣 15 金币，上面这些预期数字就不成立了。

- [ ] 三个高光点都出现：**小奖反馈 / 质疑反杀 / 收手结算**
- [ ] 结算页显示：最终金币 `250`、闯到第 3 轮、称号「欧皇候选」、本轮高光一句话
- [ ] 掐表：从点「开始」到结算页弹出 ______ 秒（要求 ≤ 180 秒）

## 5. 结算页与图鉴（阶段 3 / 阶段 5）

- [ ] 结算页有「再来一局」与「看图鉴」两个按钮。
- [ ] 点「看图鉴」：显示物品图鉴、语录图鉴、结局称号、最佳金币/最高轮次。

## 6. 商店与背包（本轮新增）

- [ ] 商店按钮在**决策阶段**与**本轮结算页**可点，其它时候变灰；点开显示 6 件商品、金币余额与「关闭」。
- [ ] 买一件背包道具（例如换门券 25）：金币立刻减少、按钮提示「去背包里用」、舞台下方出现背包栏。
- [ ] 金币不够时按钮为「买不起」且点不动；买满限购后按钮为「已满」并提示「已达上限」。
- [ ] 背包道具**只在决策阶段可点**，点「换门券」之外的背包道具会有对应反馈。
- [ ] 换门券：背包里有券时点「换门」不扣金币（券少 1 张）；没有券时换门扣 15 金币；金币不足 15 时**留在决策阶段**并给出可解释的提示（不会被拖进开奖）。
- [ ] 保险丝：买下后在背包使用，**下一次负面结算归零**（用掉即烧断，只用一次）。
- [ ] 双倍金币：买下后在背包使用，本轮收益与罚金都 ×2。
- [ ] 闭嘴卡：在决策阶段使用后，**下一轮**旁白直接沉默（本轮已念完的旁白不受影响）。
- [ ] 续命符：+1 耐心（上限 5）；耐心已满时商店会拒绝购买并提示，不会白扣 60 金币。
- [ ] 神秘盒：购买**当场开**（小奖 +30 / 小坑 −15），可以重复买；同一局面下结果随种子走，不会卡住。
- [ ] 结算页出现「商店消费」一行，金额与本次买道具花掉的金币一致。
- 记录：买到/用到的道具 ______；消费行金额 ______

## 备用方案：第 3 轮出问题怎么办（阶段 7）

若第 3 轮（大奖 → 收手）出现任何意外，**不要现场修**，直接改演「第 2 轮质疑反杀」收尾：

1. 点「重置」→「开始（演示模式）」。
2. 第 1 轮正常开到小奖（建立反馈）。
3. 第 2 轮点门 → 点「质疑旁白」→ 旁白被戳穿（+20 金币 + 真实提示）→ 坚持/换门 → 开奖。
4. 在本轮结算页直接点「见好就收」进结算页，口播说明「第 3 轮大奖环节今天略过」。
5. 结算页照常展示金币、轮次、称号与娱乐声明。

**保命四项**（时间被砍也只砍这四项之外的内容）：单轮闭环 → 质疑反杀 → 固定种子演示模式 → 一键重置。
