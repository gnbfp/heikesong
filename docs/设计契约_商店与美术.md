## 1. 硬约束（违反即打回）

1. **零构建、零外链**：双击 `index.html` 必须能玩。不加 ES module、不 fetch、不引 CDN/字体/图片外链。SVG 一律 inline。
2. **状态机不动**：`js/state.js:19-30` 的 10 个状态与清单里的迁移表保持不变。**商店不是状态，是弹层遮罩**（复用 `ui.openModal`），开关商店不触发 `setState`。
3. **`Game` 仍是唯一状态持有者**：`js/ui.js` 只读 `snapshot()` 渲染、只 `emit` 事件；不得在 ui 层改 `state`。
4. **资源只能由 `js/effects.js` 的 `applyEffect` 改写**（商店用 `Game` 自己的 `buy/useItem` 走显式扣款并 `pushLog`，不绕过 `clampInt`）。
5. **单写者**：`js/ui.js` + `style.css` 只归 ui-render；`data/*.json`+`tools/build-data.js`+`js/data.js` 只归 content-data；`tests/**` 只归 qa-verify；`index.html`+`js/state.js`+`js/game.js` 只归 Lead。**任何人都不许跑 git**（Lead 独占）。
6. 改完必须：`node --check <改的 js>` → `node tools/build-data.js` → `node tests/run-all.js` 退出码 0。
7. 中文注释、2 空格缩进、`'use strict'`、var/function 风格与现有文件一致（AGENTS.md）。

### 2.1 为什么加「换门 15 金币」

评审结论（qa-verify 2 万局模拟）：换门此前**零成本且恒为正收益**（EV +9.6~33），既让「换门券」变成废纸，也让决策没有张力。改后换门是真实取舍，券才有价值。

**行为变更（Lead 在 `js/game.js` 实现）**：`switchDoor()`
- 有 `switch_ticket` → 消耗 1 张，**不花金币**，toast「换到 N 号门（消耗换门券）」
- 无券且 `coins >= 15` → 扣 15 金币，toast「换到 N 号门（−15 金币）」
- 无券且 `coins < 15` → **不换门**，toast「换门需要 15 金币或一张换门券」，停留在 `DECIDE`

| `mute_card` | 闭嘴卡 | 20 | 2 | 背包 | 使用后**下一轮旁白闭嘴**（防剧透，非音频静音） | `mute` |

### 2.3 背包与即时道具

- 背包沿用已有字段 `state.items: [{id, count}]`（`js/state.js:60` 已有，之前只写不用）。上限：同一 id 最多 3 件。
- `mystery_box`/`patience_charm` **不入背包**，购买即结算。
- 金币不足 → toast「金币不够：需要 25，现有 10」，**弹层不关**。
- 购买成功 → `coins -= price`、`spentCoins += price`、`shopBuys++`、入包/即时结算、toast + `pushLog`，然后**重开商店弹层刷新金币显示**。

### 2.4 新增状态字段（Lead 在 `js/state.js` 加，`createInitialState`/`resetState` 都要覆盖）

| 字段 | 初值 | 用途 |
|---|---|---|
| `spentCoins` | `0` | 结算页「你在商店花了 X 金币」 |
| `shopBuys` | `0` | 图鉴/结算统计（成功购买的件数） |
| `shopBought` | `{}` | 即时商品的单局限购计数 `{ itemId: n }`（它们不进背包，只能靠这个记账） |
| `itemBuffs` | `{ fuse: false }` | 已使用的本轮增益 |
| `muteCardUsed` | `false` | 闭嘴卡**待生效**标记：沉默「下一轮」的旁白，`narrate()` 消费后立即清空（不在 `beginRound` 重置，否则卡永远拦不到旁白） |

**v2 修订（Lead，2026-10-24 晚）**：①即时商品也要吃单局限购，故新增 `shopBought`；②闭嘴卡的生效时机从「本轮」改为「下一轮」——本轮旁白在 DECIDE 之前就念完了，只有下一轮才拦得住；③`shopSpec().items[]` 新增 `unlimited`/`immediate` 布尔，且即时商品也带真实 `owned`/`cap`（`cap:null` = 不限购，`capped:true` = 置灰）。

### 3.4 背包道具使用

- 点 `.bag-slot` → `emit({ type:'use_item', id })`（`js/game.js` `action()` 新增分支）。
- `use_item` 行为：`double_coins` ♻️ 等价 `decide DOUBLE`（置 `doubled`，不消耗金币，每轮只能一次，已加倍则 toast「本轮已经加倍了」）；`mute_card` → `muteCardUsed = true` + toast「闭嘴卡：下一轮旁白闭嘴」（**下一轮** `narrate()` 才会消费它；使用后本轮剩下的质疑也一并失效，这是代价）；`fuse` → `itemBuffs.fuse = true` + toast「保险丝已接好：本轮第一次负面结算归零」；`switch_ticket` → toast「换门券不用点，换门时自动消耗」。
- 用完扣背包（`_consumeItem`，`js/game.js` 已有）。
- `narrate()` 开头：`if (s.muteCardUsed) { s.narratorLines = []; s.muteCardUsed = false; toast('闭嘴卡生效…'); setState(PICK); return; }`——**必须在这里清空标记**，`beginRound` 不许重置它。
